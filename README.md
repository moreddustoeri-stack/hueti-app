# Hueti Admin App

## Overview

The Hueti Admin App is a lightweight community-oriented administration tool designed to support childcare and educational environments with multilingual staff and limited resources.

The application helps manage subscriptions, child registrations, and administrative workflows across two physical locations.

---

## Purpose

This project is not a commercial SaaS product.

It is designed to support a small childcare organization operating in a socially-oriented and partially non-profit environment. Most revenue is used to cover operational costs such as rent and fair compensation for staff members, including individuals from socially or integration-challenged backgrounds.

Some staff members have limited German language skills, therefore the system aims to simplify administrative processes and reduce errors through structured digital workflows.

---

## Locations

- Childcare facility (“Hueti”)
- Educational institution offering German and literacy (basic language courses)
